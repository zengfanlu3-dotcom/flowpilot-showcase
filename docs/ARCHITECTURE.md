# FlowPilot 架构摘要

```text
浏览器（Assistant / Evaluation 冻结快照）
  │ 同源 HTTPS
  ▼
Node Web Service
  ├─ /api/assistant/decide → 访问限额与超时 → 结构化模型判断
  │                         → 本地 Schema 校验 → Policy / 状态校验
  │                         → 按需知识检索 → 有依据的回答 → 用户可见响应
  ├─ /health → 最小健康状态
  └─ 其他路径 → Vite 构建的静态页面
```

模型负责提出结构化判断，不直接执行权限变更或真实工单操作。程序验证事实证据、风险和动作前置条件；当前用户纠正事实时，依赖旧事实的方案状态会失效。知识回答使用演示 IT 文档，支持来源引用、部分可回答与明确拒答；证据校验避免无依据断言。

Evaluation 具有模型层与最终产品层两个结果。公开页面只显示冻结的已审查快照，不提供 live rerun，也不公开原始模型输出、内部运行记录或完整 Prompt。固定 30 条测试检验核心场景，不是开放分布 Benchmark。

公网保护仅作用于访问入口：限频、每日额度、消息长度、超时及服务不可用提示。完整应用由私有仓库部署；本公开仓库只包含说明、证据摘要和少量经审查的代码示例。
